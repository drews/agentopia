# agent-runtime Spec Delta

## ADDED Requirements

### Requirement: Persona agents run on a validated local-LLM runtime

Each crew persona SHALL be backed by a PydanticAI Agent configured with the persona's system prompt and a local Ollama model, replacing the raw LangChain chat path. The homegrown `agent_manager` SHALL remain the orchestrator for persona selection, ambient behavior, and scheduling.

#### Scenario: Crew chat uses the local runtime

- **WHEN** a user sends a chat message to a crew agent with `DEFAULT_LLM_PROVIDER=ollama`
- **THEN** the reply is generated by that persona's PydanticAI agent against the local Ollama model and broadcast over WebSocket
- **AND** no `langchain` code path is exercised

#### Scenario: Mock provider still works for tests

- **WHEN** the backend runs with `DEFAULT_LLM_PROVIDER=mock`
- **THEN** agents return deterministic mock responses without requiring Ollama to be running

### Requirement: Tool calls are validated and self-corrected

The runtime SHALL validate every model-emitted tool call against the tool's JSON schema before execution, and on validation failure SHALL re-prompt the model with the validation error up to 2 retries before falling back to a plain-language failure message.

#### Scenario: Malformed tool call is repaired

- **WHEN** the model emits a tool call with arguments that fail schema validation
- **THEN** the runtime re-prompts with the validation error and the corrected call executes, without surfacing an error to the user

#### Scenario: Persistent failure degrades gracefully

- **WHEN** tool-call validation fails after 2 retries
- **THEN** the agent responds in persona explaining it could not complete the action, and the failure is logged with the raw model output
