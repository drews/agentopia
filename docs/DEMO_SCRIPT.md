# Agentopia Demo Script - Impressive Dad Demo

## Quick Setup (30 seconds)
1. **For Dad**: "Let me just start up my application..." 
2. **You do**: Run `./dev.sh start` (already running!)
3. **Then**: Open browser to http://localhost:3000 
4. **Present**: "This is my Star Trek bridge productivity system"

## Demo Flow (5-10 minutes)

### Opening Hook (1 minute)
**"Dad, remember watching Star Trek? Well, I built my own starship bridge that actually helps me get work done."**

Point out key visual elements:
- **LCARS Star Trek design** - "This is the authentic Star Trek computer interface"
- **Live agent movement** - "Watch the crew members moving around the bridge in real-time"
- **Professional status displays** - "All the systems are actually working and connected"

### Core Feature Demo (3-4 minutes)

#### 1. Bridge Operations Tab (Currently Active)
- **Point to the agents moving**: "These aren't just animations - they're AI crew members"
- **Show the sidebar**: "Real-time crew status and system monitoring"
- **Highlight the professional interface**: "Everything updates live through WebSocket connections"

#### 2. Roster Tab 
- Click on "Roster" tab
- **Show character profiles**: "Each crew member has their own personality and expertise"
- Point out:
  - Commander Data (Strategic Planning)
  - Lt. Spock (Research & Analysis) 
  - Chief O'Brien (Task Execution)

#### 3. Game Mechanics Tab
- Click on "Game Mechanics" tab  
- **Chat with agents**: Type messages like:
  - "What's our mission status?" 
  - "Analyze the current situation"
  - "Execute priority tasks"
- **Show intelligent responses**: Agents respond with specific technical details and emojis
